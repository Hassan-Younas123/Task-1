# Customer Churn Prediction

Machine learning project to predict customer churn using a Random Forest model compared against a Logistic Regression baseline.

## Files
- `src/churn.py` — main script
- `data/customer_churn_dataset-testing-master.csv` — dataset
- `requirements.txt` — Python packages needed

## How to run
1. Install requirements: `pip install -r requirements.txt`
2. Run: `python src/churn.py`
